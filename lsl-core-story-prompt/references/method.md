# 方法论（v0.1，对应 skill v0.1.0）

一句话：**先写一句能拍的核心，再把它落到人、物、场景、秒数上，最后回头查漏洞。** 换什么剧本，这个顺序都不变；随剧本变的只有核心的句式和贯穿物的种类。

## 一、方法从哪来

六步每一步都有成熟的来源；这里做的是把它们串起来，并且都往“能拍”上推了一步。

| 步骤 | 借的经典方法 | 原来讲什么 | 我们改了什么 |
|---|---|---|---|
| 1 核心句 | 埃格里《编剧的艺术》的“前提”；麦基《故事》的“主控思想”；斯坦尼斯拉夫斯基的“最高任务”；卡赞的“脊柱” | 一句话说清这部戏的意义，或人物最终要什么 | 原方法停在“意义”，可以写成“伟大的爱能战胜死亡”。我们加了能拍测试：必须落到人、东西、动作、变化，不许有抽象词 |
| 2 贯穿物 | 契诃夫之枪；斯坦尼斯拉夫斯基的“贯穿动作” | 出现过的东西后面要用上；人物有一条从头贯到尾的动作线 | 把“贯穿动作”落到一件拿在手上的东西上，按秒记它的去向 |
| 3 人物 | 斯坦尼斯拉夫斯基的“任务”；卡赞的脊柱；马梅《导演功课》的“他想要什么” | 演员每场演一个具体目标，不演情绪 | 加一列“不做什么”（比如不哭），用来管全片哪里收、哪里放 |
| 4 场景 | 场面调度 | 空间、陈设、走位一起讲故事 | 每个地方必须说得出它在核心里干什么用，说不出就不加 |
| 5 节拍 | 斯奈德《救猫咪》节拍表；皮克斯故事脊柱（从前……每天……直到有一天……最后……） | 把故事切成有顺序的节拍点 | 按秒排，每拍加一列“核心走到哪” |
| 6 检查 | 麦基“每场戏都要让价值发生转变”；契诃夫之枪反着用 | 没有推进的场要删；出现的东西要有交代 | 变成两条能逐行对的检查：最后一列填不出的拍、没交代去向的物件 |

这些方法本身经过了几十年的实践。串成六步、加上能拍测试和按秒的去向表，是本项目新加的，v0.1 只在《梦浮生》（情感）上验证过。

## 二、哪些通用、哪些随剧本变

| 东西 | 通用还是随剧本变 | 说明 |
|---|---|---|
| 六步的顺序 | 通用 | 先核心，再物、人、景，再按秒排，最后检查 |
| 能拍测试 | 通用 | 人、东西、反复的动作、最后的变化，四样缺一不可 |
| 物件去向检查 | 通用 | 出现过的东西都要交代最后在哪 |
| 节拍表最后一列 | 通用 | 每一拍都要说得出核心走到哪 |
| 提案单列、剧本不删 | 通用 | 导演加的东西全部标提案，由人取舍 |
| 两层核心 | 通用 | 集核心 → 段核心；段核心是集核心的一步 |
| 核心的句式 | 随剧本变 | 见 `templates.md` |
| 贯穿物的种类 | 随剧本变 | 一封信、一件产品、一次伤、一条线索，也可以是一句反复说的话 |
| 节拍密度 | 随剧本变 | 《梦浮生》120 秒 26 拍；快节奏的打斗或带货片可能要翻倍 |
| 人物表的行 | 随剧本变 | 一个主角时按段列；多人戏按人列，每人一句“脊柱” |

## 三、六步怎么做

每一步的产物都是具体的东西：一句话、一张物件图、三张表、一份漏洞清单。

1. **写一句能拍的核心。** 句子里必须有一个人、一件看得见的东西、一个反复做的动作、最后的变化；不许出现“爱、坚守、思念、家国”这类拍不出来的词。先写集核心，再写段核心（每段是集核心的一步）。
2. **列贯穿物。** 核心里那件东西，加上跟它有关的几件（共 3—6 样），每件写清：第几秒出现、在谁手上、变成什么样、最后去了哪。
3. **定人物。** 每一段：想要什么、手上在做什么、不做什么（比如“不哭”）、对方以什么样子在场。
4. **定场景分工。** 每个地方在核心里干什么用，里面放哪些东西、东西在哪。
5. **按秒排节拍。** 每一拍写清场景、人、物、怎么演；最后一列写“核心走到哪一步”。只写到节拍，不拆镜头。
6. **回头检查。** 每一拍的最后一列填得出来吗？每件东西有没有交代去向？填不出、没交代的，就是要补的漏洞。

第 1 步由人拍板；后面五步是从它推出来的，改了核心，后面的表会跟着变。

## 四、七个可复用机制（换剧本只换内容、不换格式）

| 机制 | 做什么 | 产出 |
|---|---|---|
| 1 划分“已定”和“空着” | 读剧本，列出已经定的（事件、台词、字幕、时长）和空着的（谁先动、怎么演、东西在哪） | 已定 / 待设计清单，已定的一句不改 |
| 2 核心候选 | 按剧本类型套句式，给 3 个方向不同的核心，每个附“选它会变什么” | 人选定的一句核心 |
| 3 能拍测试 | 逐项对人、东西、动作、变化；有抽象词就改写 | 过了测试的核心句 |
| 4 四张表 | 物件去向（加泳道图）、人物、场景、按秒节拍，列名固定 | 具体到人、物、景、秒的调度 |
| 5 自动检查 | 物件去向、每拍最后一列、秒数合计、全片规矩、台词字幕有没有漏 | 漏洞清单，每条附修法 |
| 6 交接给导演 skill | 整理成“已确认决定清单”；导演 skill 当作事实，有新想法只能标提案 | 剧情核心提示词 |
| 7 人的参与点 | 两处必须人拍板：选核心、取舍提案；其余随时标注、改写 | 每轮结束时的“待你定”清单 |

## 五、人怎么参与

- **只改核心一句，后面跟着变。** 例：《梦浮生》核心换成“一个人的团圆，是两岸团圆的缩影”，贯穿物就从信换成水和山（窗上的雨、渡轮、两岸），渡海从 5 秒变成全片最长的一段，码头可以加群演，节拍表最后一列全部重写。
- **在候选文字上标注。** 选中几个字写意见；标注是下一轮生成的硬条件，也是方法论的原始数据（见项目宪法“方法论怎么升级”）。
- **取舍提案。** Claude 额外加的设计一条条留或删。
