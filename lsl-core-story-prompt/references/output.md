# 输出与交接

## 剧情核心提示词（固定格式）

工作台第 11 节点按档案自动合成；对话模式照同样的格式写。顺序和小标题不改，没有内容的小节整节不写。

```
【剧情核心提示词】<剧名和集数>
集核心：<一句>

段核心：
- <段号> <段名>（a–b）N 秒：<一句；没选写“（未选）”>

全片规矩：
1. <一条>

贯穿物去向：
- <物>（<在核心里是什么>）：第 N 秒 <在哪、什么样> → 第 N 秒 …；最后：<在谁手上、在哪>

人物：
- <段> · <几岁>：想要<…>；手上做的事：<…>；不做：<…>；他：<对方以什么样子在场>

场景：
- <场景>（<出现在哪几段>）：<在核心里干什么>。<放什么、东西在哪>

节拍（按秒）：
- （a–b）N 秒｜<场景>｜<人>｜<物>｜<怎么演>｜核心：<走到哪>

保留的导演提案：
- <在哪>：<提案>

人工标注（原话）：
- <段号或“集核心”>“<选中的字>” → <意见>

交接：以上为已确认的事实，导演 skill 写详稿和投喂版时不重新决定；新的想法只能标“提案”。
```

写法规矩：

- 时间一律“（a–b）N 秒”。
- “怎么演”写看得见的动作和结果，不写形容词情绪。
- 删掉的提案不出现；用户的标注照原话抄，不改写。
- 引用歌词的字幕写“（剧本字幕）”。

## 交给导演 skill 的开始提示词

```
/director-video-prompt
项目：<剧名>。剧本见附件。
目标：即梦 Seedance 2.5，单段 ≤15 秒，图片写 @图片N。
本次重点：按下面的剧情核心提示词写导演详稿和投喂版，里面的决定当作已确认的事实。

<剧情核心提示词全文>
```

用法：开一个新对话，附上剧本，把这段贴进去。

## 导演 skill 怎么用它（交接约定）

| 剧情核心提示词里的 | 导演 skill 当作 | 能不能改 |
|---|---|---|
| 集核心、段核心 | 每段叙事的依据 | 不改；有更好的想法写成“提案” |
| 贯穿物去向 | 道具卡和逐镜的物件位置 | 不改去向；可以补外观细节 |
| 人物表 | 表演和人物知情 | 不改“想要 / 不做”；可以细化到每镜的动作 |
| 场景表 | 地点块、方位和布局 | 可以补机位和陈设细节，不改东西在哪 |
| 节拍 | 每段的时间轴和关键节拍 | 段落起止不改；拆几镜、每镜几秒由导演 skill 定 |
| 全片规矩 | 全片约束 | 不破 |
| 保留的提案 | 已确认的事实 | 不删 |

交接后出的详稿和投喂版，按 `qa.md` 的 Q2 抽查。
